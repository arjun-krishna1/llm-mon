# LLMMON Mythos — Vertical Slice Plan

Goal: a short, genuinely polished monster-collecting RPG slice in the style of
GBA-era handheld RPGs, where the creatures are LLMs. Title → professor intro →
arrive in Hayes Valley with Mom → rescue the professor and choose a starter →
walk Route 101 → arrive in SoMa Node.

This file is the contract between workstreams. If you are an agent executing
one workstream: read sections 1–4 fully, then your workstream in section 6.
Only write files your workstream owns. Do not run `git commit`, `git add`,
`git stash`, `git checkout` or `npm install` — other agents share this tree.

## 1. Why a rebuild

The previous build (`legacy/`) was a React slideshow of CSS-drawn scenes with
a small RPGJS canvas embedded in a dashboard: no real game loop, three
clashing art styles, 32px RPG-Maker tiles, free-pixel movement, web fonts.
Nothing about it reads as a handheld RPG. `legacy/` is kept only as a content
reference (names, flavour text, stats) and is excluded from build and lint.

## 2. Pillars (the quality bar)

1. **Native 240×160, integer-scaled, nearest-neighbour.** Everything is
   authored at 1× on a 16px tile grid. No sub-pixel positions, no smoothing,
   no CSS/DOM UI, no web fonts — bitmap font only.
2. **Grid-locked movement that feels right.** 16px steps, 16 frames per tile
   walking (≈267 ms), 8 frames running (hold B), tap-to-turn, bump sound on
   walls, two-frame walk cycle, camera locked on the player, ledge hops,
   tall-grass rustle, door open → fade → interior.
3. **One cohesive art style from one palette** (`tools/art/palette.py`).
   Bright, saturated, sunny; dark warm outlines on objects; top-left light;
   soft textured ground. Every piece of art is generated by a script in
   `tools/art/` so it can be iterated and stays licence-clean.
4. **Everything original.** We match the genre's *feel and mechanics*. We do
   not copy any existing game's sprites, tiles, maps, music, characters, fonts
   or iconography (no red/white capture balls, no red-roofed healing centre
   with a ball logo, no white-hat protagonist). Map layouts are our own.
5. **Text presentation.** Mixed-case dialogue, typewriter reveal, two-line
   message box, bouncing advance arrow, A to advance / hold to speed up.
6. **Juice.** Screen fades, battle transition wipe, HP bars that drain
   smoothly, sprite slide-ins, hit flash + shake, faint drop, EXP bar fill,
   level-up jingle, area-name banner when entering a zone, music per area.

## 3. Tech decisions

| Area | Decision | Why |
| --- | --- | --- |
| Engine | Phaser 3.90 + TypeScript + Vite | Mature tilemap, camera, input, tween, pixel-art pipeline; huge docs; no beta APIs. |
| Maps | Tiled JSON (`.tmj`, embedded tilesets) | Engine-native in Phaser, and hand-editable in the Tiled editor later. |
| Map authoring | ASCII-layer Python DSL in `tools/maps/` → `.tmj` | Agents can author and diff maps without a GUI; output still opens in Tiled. |
| Art | Python + Pillow generators in `tools/art/` | Reproducible, palette-locked, original. |
| Creatures | Existing generated art downscaled to 64×64, ≤15 colours + outline | Tested: reads well at GBA scale. |
| Audio | WebAudio chiptune synth in TS (no audio files) | Original music/SFX, tiny bundle, no licensing. |
| State | Plain TS singleton + `localStorage` save | Simple, testable. |
| Tests | Vitest for battle maths; Playwright scripts in `tools/playtest/` | Battle logic is pure; playtests drive the real game. |

Controls: arrows/WASD move · Z/Space/Enter = A · X/Shift = B (hold to run) ·
Enter/Esc = Start menu. Touch controls are out of scope for the slice.

### 4.2 Rendering

- Phaser config: 240×160, `pixelArt: true`, `roundPixels: true`,
  `Scale.FIT` + `autoCenter`, parent `#game`. Zoom must snap to an integer
  multiple when the window allows (compute the largest integer scale and size
  the canvas CSS explicitly on resize).
- Depth order in the overworld: tile layers below → characters sorted by y →
  tile layers whose name starts with `over` → weather/fx → UI scene.

### 4.3 Tilesets

- 16×16 tiles, PNG, 16 columns wide, no margin/spacing, transparent where empty.
- Each tileset ships `<name>.png` plus `<name>.tsj` (Tiled tileset JSON) with
  per-tile custom properties, plus `<name>.catalog.json`:
  `{ "tiles": { "grass_a": 0, ... }, "stamps": { "house_orange": { "w": 5, "h": 5, "layers": { "base": [[id…]…], "over": [[id…]…] } } }, "autotiles": { "path": { "c":…, "n":…, …13 pieces… } } }`
  (`-1` = empty cell). The catalog is what map authors use; name things clearly.
- Tile properties (all optional): `solid: bool`, `grass: bool` (tall grass:
  encounters + rustle), `ledge: "down"|"left"|"right"` (one-way hop),
  `counter: bool` (solid, but A-press interacts with the NPC behind it),
  `water: bool` (solid for now), `door: bool` (plays door-open anim/sfx when
  a warp sits on it). Animated tiles use Tiled's standard `animation` array.

### 4.4 Maps (`public/assets/game/maps/<id>.tmj`)

- Orthogonal, 16px, tilesets **embedded**, finite, CSV or array data.
- Tile layers, drawn in file order. Convention: `ground`, `detail`, `detail2`
  below characters; `over`, `over2` above. A cell is blocked if any layer's
  tile there is `solid`.
- One object layer `objects`. Object `type` (Tiled class) and properties:
  - `spawn` — `name`. Player entry points. Point or tile-sized rect.
  - `warp` — `toMap`, `toSpawn`, optional `facing`, `sfx` ("door"/"stairs"/"exit"). Triggered by stepping on it.
  - `npc` — `id`, `sprite`, `facing`, `movement` ("static"|"look"|"wander"), `script` (script id run on A-press), optional `sight` (tiles; trainers), `hideIfFlag`, `showIfFlag`.
  - `sign` — `text` (use `\n` / `\f` for line / page breaks) or `script`.
  - `trigger` — rect; `script`; runs when the player steps in; `once` flag name optional; `ifFlag` / `unlessFlag` optional.
  - `item` — `itemId`, `count`, `flag` (ground pickup, drawn with `sprites/fx/item_ball.png`).
  - `zone` — rect; `name` (area banner text), `music`, `encounters` (table id). Entering a different zone shows the banner and cross-fades music.
- Map properties: `music`, `indoor: bool`, `name`.
- The outdoor world is ONE seamless map `overworld` (Hayes Valley at the south,
  Route 101 in the middle, SoMa Node at the north) so there are no loading
  seams outdoors. Interiors are separate small maps.

### 4.5 Sprites (`public/assets/game/sprites/`)

- `chars/<id>.png` — 48×96 sheet: 3 columns × 4 rows of 16×24 frames.
  Rows: down, up, left, right. Columns: stand, step-A, step-B. The character
  stands on the bottom 16px; feet baseline 2px above the frame bottom.
  Walk cycle = stand → A → stand → B.
  Required ids: `player`, `mom`, `prof`, `aide`, `boy`, `girl`, `man`,
  `woman`, `elder`, `techie`, `nurse`, `clerk`, `trainer_m`, `trainer_f`.
- `mons/<speciesId>_front.png` 64×64, `mons/<speciesId>_back.png` 64×64,
  `mons/<speciesId>_icon.png` 32×32 sheet of two 16×16 frames (party icon bob).
  Species ids: `claude_fable`, `gpt_5_5`, `glm`, `hallucihound`, `gemma_4`,
  `gpt_5_4_mini`, `mistral_medium`, `gemini_flash`, `claude_haiku`,
  plus any other source art that converts well.
- `fx/` — `emote_exclaim.png` (16×16), `grass_rustle.png` (4×16×16 strip),
  `grass_overlay.png` (16×16; covers the feet of a character standing in tall
  grass), `item_ball.png` (16×16), `shadow.png` (16×8), `orb_throw.png`
  (Prompt Orb, 4×16×16: closed, tilt-left, tilt-right, open),
  `door_*.png` if doors animate as sprites, `truck.png` (moving truck, ≈48×40),
  `satchel.png` (16×16 on-ground bag).
- `battle/` — `bg_grass.png` 240×112 (sky + field), `platform_enemy.png`,
  `platform_player.png`, `trainer_back.png` (player back sprite 64×64, 4 throw
  frames → 256×64), `prof_front.png` (64×96 intro portrait sprite),
  `trainer_m_front.png`, `trainer_f_front.png` (64×64).
- `ui/` (`public/assets/game/ui/`) — `frame_dialog.png`, `frame_menu.png`,
  `frame_battle.png` (24×24 9-slice sources, 8px corners), `hud_enemy.png`,
  `hud_player.png` (battle name/HP plates sized for 240×160), `hpbar` colours
  documented, `cursor.png` (8×8 ▶), `arrow_down.png` (8×8 ▼, advance arrow),
  `title_bg.png` 240×160, `title_logo.png`, `type_<id>.png` 32×12 type chips,
  `orb_slots.png` (party count pips), `starter_select_bg.png` 240×160.
- Missing-asset tolerance: the engine must still boot when a file is missing
  (generate a flat magenta-outlined placeholder texture of the contract size
  on load error) so workstreams can land in any order.

### 4.6 Runtime types

`src/game/types.ts` holds `MonInstance`, `BattleRequest`, `BattleResult`,
`SaveData`. Battle is started with
`scene.scene.launch('Battle', { request, onDone })`; the battle scene mutates
`state.party` / `state.bag` and calls `onDone(result)` after its own fade-out.

### 4.7 Audio API (`src/game/audio/index.ts`)

`audio.unlock()`, `audio.playMusic(id, opts?)`, `audio.stopMusic(fadeMs?)`,
`audio.sfx(id)`, `audio.setVolume(music, sfx)`. Unknown ids are a no-op with a
console warning. Music ids: `title`, `intro`, `hayes_valley`, `home`, `lab`,
`route_101`, `soma_node`, `center`, `battle_wild`, `battle_trainer`,
`victory`, `encounter_trainer`. SFX ids: `select`, `cancel`, `text`, `bump`,
`door`, `stairs`, `exit`, `ledge`, `grass`, `menu_open`, `save`, `heal`,
`item_get`, `key_item_get`, `level_up`, `hit`, `hit_super`, `hit_weak`,
`faint`, `orb_throw`, `orb_shake`, `orb_catch`, `orb_break`, `run`, `exp`,
`low_hp`, `battle_start`, `stat_up`, `stat_down`, `exclaim`.

### 4.8 Debug + playtest hooks

With `?debug=1`: `window.__llmmon = { state, info(), warp(map, spawnOrX, y?),
setFlag(k, v), giveMon(speciesId, level), battle(request), heal() }` where
`info()` returns `{ scenes: string[], map, x, y, facing, dialogOpen, dialogText,
menuOpen, zone, busy }`. `?seed=N` seeds all RNG. `?fast=1` makes text instant
and skips fades (for automated playtests). `?new=1` ignores any save.

## 5. The slice (content outline)

World: you move to **Hayes Valley**, a small sunny town. **Route 101**
("Octavia 101") runs north to **SoMa Node**, the first real town.

1. **Title** → New Game / Continue.
2. **Professor intro** (black stage, spotlight): Prof. Karpathy introduces
   LLMMON, shows one, asks your name (pick from 4 presets or keep "Arjun").
3. **Arrival**: fade in outside your new house, the Mythos Movers truck is
   parked, Mom greets you and walks you in.
4. **Home 1F**: Mom: your room is upstairs. **Home 2F**: bed, desk PC
   (flavour), a notebook that teaches controls. Coming back down, Mom says the
   professor's lab called — go say hello.
5. **Hayes Valley**: ~6 NPCs with real personality, signs, mailbox, neighbour
   house, the lab. In the lab the Aide says the professor went up Route 101
   and forgot his satchel.
6. **Route 101 mouth**: stepping north triggers the rescue: the professor is
   cornered by a glitching **HalluciHound**. "Grab a LLMMON from my satchel!"
7. **Starter select**: satchel screen, three Prompt Orbs, pick Claude Fable /
   GPT 5.5 / GLM, with confirm.
8. **First battle** vs HalluciHound Lv2 (cannot run, cannot lose badly).
9. **Lab**: professor thanks you, you keep the starter, receive the PromptDex
   and 5 Prompt Orbs; Mom gives Running Shoes-equivalent ("Fast Tokens") on
   the way out. The route north opens.
10. **Route 101**: tall grass with wild Gemma 4 / GPT-5.4 mini / Mistral
    Medium (rare Gemini Flash), ledges that shortcut the way back, a hidden
    item, two trainers with sight-line battles, a couple of flavour NPCs/signs.
11. **SoMa Node**: Model Center (heals party), Token Mart (buy Prompt Orbs /
    Patches), 5–6 NPCs, a gym-shaped building that is closed ("The Alignment
    Gym opens in the next build"), and an end-of-slice thank-you sign.

Systems in scope: party screen, summary screen, bag (use Patch, throw Prompt
Orb), catching, EXP/level-up/learn move, trainer sight + battle, heal, shop,
save/continue, start menu, white-out → respawn at last heal point.

Tone: warm, lightly funny, AI in-jokes that a non-expert still enjoys
(context windows, hallucinations, tokens, benchmarks, alignment). No walls of
text: 1–3 boxes per NPC.

play → critique → fix loop run by the lead.

**AUDIO.** `src/game/audio/**`: WebAudio chiptune engine (pulse ×2, triangle,
noise; envelopes, vibrato, simple echo), a compact pattern format, all music
and SFX ids in 4.7 as original compositions, looping, cross-fades, ducking for
jingles, unlock on first input.

### Wave 2

**CONTENT.** `tools/maps/**` DSL + all maps (`overworld`, `home_1f`,
`home_2f`, `neighbor`, `lab`, `center`, `mart`, one SoMa house) and
`src/game/content/**` scripts implementing section 5 end to end.

**BATTLE-UI.** `src/game/scenes/BattleScene.ts` (+ `src/game/battle/ui/**`):
full battle presentation on top of BATTLE-CORE events, starter-select scene,

### Wave 3 — play, critique, fix

The lead plays the slice start to finish with Playwright
(`tools/playtest/`), screenshots every beat at 1× and 4×, writes a ranked
critique (feel, art, pacing, bugs), dispatches fixes to the owning
workstream, and repeats until a full run has no P0/P1 issues.

## 7. Definition of done for the slice

- Fresh load → SoMa Node playable start to finish without debug hooks, no
  soft-locks, no console errors; save/continue works mid-way.
- `npm run lint`, `npm run build`, `npm test` pass.
- Every screen holds up at 1× (240×160): no mixed pixel densities, no
  smoothing, no text overflow, no placeholder art.
- Movement, text and battle pacing feel like a handheld RPG, not a web app.
